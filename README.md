# 黄梦辉 · 个人作品集

一个使用原生 HTML / CSS / JavaScript 开发的个人作品集静态站点，沉稳杂志式排版，兼容桌面端与移动端，支持深浅色主题切换。

## 功能特性

- **深浅色主题切换**：顶部导航栏右侧按钮一键切换，通过 `localStorage` 记忆用户选择，并在页面渲染前确定主题以避免闪烁。
- **项目作品展示与分类筛选**：作品数据来自 `js/data.js`，支持按类别筛选（AI 应用 / 数据可视化 / Web 应用 / 小程序）。
- **滚动渐显动画**：区块与作品卡片进入视口时淡入上移。
- **导航滚动高亮**：滚动时自动高亮当前所在区块，导航栏滚过首屏后增加毛玻璃背景。
- **移动端响应式布局**：窄屏下折叠导航菜单，版式自适应。
- **纯静态、零依赖**：不依赖任何前端框架或第三方 UI 组件库。

## 技术栈

- HTML
- CSS（CSS 变量实现双主题）
- JavaScript（原生，无框架）

## 运行方式

项目为纯静态页面，无需安装依赖或构建，两种方式任选其一：

1. 直接用浏览器打开 `index.html`。
2. 在项目根目录启动本地静态服务器（任选其一）：

```bash
# Python
python -m http.server 8000

# Node.js（需安装 serve）
npx serve .
```

然后在浏览器访问 `http://localhost:8000`。

## 主要功能说明

- **主题切换**：`document.documentElement` 的 `data-theme` 属性在 `light` / `dark` 间切换，页面背景、文字、边框颜色由 CSS 变量统一驱动；选择结果写入 `localStorage('theme')`。
- **项目渲染**：`js/data.js` 中的 `PROJECTS` 数组按顺序渲染，版式自动交替（首个为全宽大图，其后左图右文 / 左文右图交替）。
- **分类筛选**：顶部筛选按钮根据 `PROJECTS` 中的 `category` 字段动态生成，点击后在列表中过滤展示对应类别作品。
